## 1. 요구사항 구체화와 완료 기준

### E1. 노드 카드 — 제목과 내용 (에디터)
- 카드 = **제목**(굵게, 큰 글씨) + 구분선 + **내용**(`note`, 보통 글씨·muted 아님). 내용이 없으면 내용 영역 숨김.
- 내용은 줄 수만큼 카드가 세로로 길어지고, 그래프 재배치(겹침 없음)가 즉시 반영된다.
- 내용 서식: 줄머리 `- `, `+ `, `* ` 입력 시 그 줄이 불릿으로 바뀜(저장은 `- `로 통일). 텍스트 선택 후 **Shift+H** → 형광펜(마지막으로 쓴 색, 기본 노랑). 선택 없이 Shift+H는 그냥 'H' 입력.
- 제목·내용 각각 **더블클릭 → 그 자리에서 편집**. Esc/바깥 클릭 = 확정. 한글 IME 조합 중 Enter/Tab/Shift+H 단축키 무시.
- **너비 3단계**: 카드 왼쪽·오른쪽 가장자리(핸들)를 끌면 가장 가까운 단계(1·2·3)로 스냅. `TreeNode.width` 저장, 실행취소 1단계. 기본 1단계. px 값은 E가 정함(예 180/260/360). 제목·내용은 폭 안에서 줄바꿈.
- 오답 색: `missHeat(srs)` 0..1 에 비례해 카드 배경/테두리가 붉어짐(0 = 색 없음). 학습 모드에서 틀리면 진해지고 맞히면 옅어짐.
- **완료 기준**: 내용 3줄(불릿 2 + 형광펜 1) 카드가 3줄 높이로 그려지고 겹침 없음, 너비 핸들 드래그로 단계 변경·새로고침 유지·Ctrl+Z 복구, miss 2인 노드가 miss 0 노드보다 붉음.

### E2. 우측 패널
- 마우스 클릭 또는 방향키로 선택이 바뀌면 그 노드의 **제목·내용 편집 영역**이 패널에 나온다(노드 카드와 같은 데이터, 양방향 즉시 반영).
- 툴바: 불릿 토글 아이콘, 형광펜 3색(분홍·노랑·하늘) 아이콘, 형광펜 지우기. 선택 영역에 적용.
- **자동 정렬** 버튼을 패널로 이동(헤더에서 제거). 개요 붙여넣기/내보내기는 패널 하단 접이식으로 유지.
- 허용 표현(aliases) 입력은 제거(타이핑 채점 제거로 쓸모 없음). 필드는 타입에 남김.

### F1. 플래시카드
- 시작 개념(쿼리 `root`, 없으면 루트) **하나만** 화면 중앙에 크게. 하위 개념은 가려진 채 "하위 N개"만 표시.
- 상위 카드를 클릭/탭(또는 Space/Enter) → 하위 노드들이 애니메이션으로 펼쳐짐(순차 등장, `prefers-reduced-motion` 존중).
- 펼쳐진 각 하위 노드에 **[알음] / [모름]** 버튼. 누르면 `recordResult(nodeId, treeId, known)` + `logEvent('flash_rated', { nodeId, known })`, 버튼 대신 결과 표시(다시 누르면 변경 가능 — 마지막 값만 기록하도록 한 번 더 기록해도 됨: 가정 F-a).
- 다음 개념으로: 하위 노드 중 자식이 있는 노드를 눌러 **더 들어가기**, 또는 **다음** 버튼 = 전위 순서상 다음 "자식 있는 노드". 끝나면 요약(알음/모름 수).
- **상태 색**: 화면의 모든 노드 카드에 `colorMap`(core/srs) 기반 색 — 초록(외움) / 연두 / 빨강(모름) / 없음. 평가 직후 즉시 반영.
- **미니맵**: 화면 한쪽(오른쪽 위 고정)에 전체 트리 축소판(위→아래, `graph/layout.ts` 재사용, 고정 크기 measure). 노드는 상태 색 점/박스, **현재 개념과 그 하위를 강조**. 미니맵 노드 클릭 → 그 개념으로 이동(자식 있는 노드만).
- **완료 기준**: 루트 → 탭 → 하위 3개 펼침 → 알음 2·모름 1 → 색 초록/빨강 반영 → 다음 개념 이동 → 미니맵 강조 위치 변경. 새로고침 후 색 유지.

### F2. 오늘의 복습
- 오늘 기한 노드의 부모들을 큐로, 플래시카드 화면으로 차례로 복습(F1 컴포넌트 재사용). 목록 `ul[aria-label="복습 대상 트리"] li[data-tree-id]` 유지.

### D1. 드래그 앤 드롭 퀴즈
- 범위: 헤더 도구 슬롯에 범위 선택(select, 자식 있는 노드들). 기본 루트.
- 화면 상단: 범위 트리의 **뼈대** — 자식이 있는 노드(내부 노드)는 제목 표시, **리프 노드는 빈칸**(슬롯). 슬롯은 해당 부모 아래 자리 수만큼.
- 하단: 리프 노드 카드들이 **섞인 채** 흩어져 있음(트레이). 카드를 끌어 슬롯에 놓기 / 슬롯 간 이동 / 트레이로 되돌리기. 마우스·터치(pointer 이벤트).
- **채점**(모든 카드 배치 후 또는 언제든 "채점"): 카드가 원래 부모 아래 슬롯에 있으면 정답(같은 부모의 슬롯끼리는 순서 무관, 제목이 같은 카드는 서로 교환 가능). 슬롯별 정오 표시 + 정답 보기. 각 리프 `recordResult`, `logEvent('dnd_attempt_completed', { mode: 'dnd', rootId, total, correct })`.
- 리프가 0개(범위가 리프)면 안내 문구.

### D2. 백지 드래그 앤 드롭 퀴즈
- 백지 캔버스에 범위 루트만 놓여 있음. 트레이에 **범위의 나머지 모든 노드**(내부+리프)가 섞여 있음.
- 트레이 카드를 캔버스의 노드 위로 끌어 놓으면 그 노드의 **자식**으로 붙고, 위→아래 트리로 자동 배치(`graph/layout.ts` 재사용). 배치된 카드를 다른 노드로 옮기거나(자손 포함 이동, 자기 자손 아래 금지) 트레이로 되돌릴 수 있음.
- **채점**: 노드마다 "사용자가 붙인 부모 == 원래 부모"면 정답, 트레이에 남은 노드는 오답. 형제 순서 무관. 결과 색 표시 + 원본 트리 나란히 보기. 각 노드 `recordResult`, `logEvent('dnd_attempt_completed', { mode: 'blank_dnd', ... })`.

## 2. 가정
- F-a. 플래시카드에서 같은 노드를 다시 평가하면 다시 기록한다(FSRS 에 두 번 반영). 단순함 우선.
- F-b. 루트(시작 개념) 자체는 평가하지 않는다. 평가 대상은 펼쳐진 하위 노드.
- D-a. D&D 퀴즈의 빈칸은 리프만. 깊은 트리에서 중간 노드 암기는 백지 D&D 와 플래시카드가 담당.
- D-b. 정답 판정은 부모 일치만(형제 순서 무관). 제목이 같은 노드는 같은 것으로 본다.
- E-a. 내용 서식은 불릿(1단계)과 형광펜 3색만. 굵게·링크·중첩 불릿 없음.
- E-b. 에디터 키보드 H(접기)는 탐색 모드에서 그대로. Shift+H 는 내용 편집 중에만 형광펜.
- 공통: 학습 결과는 모두 `recordResult` 한 함수로 기록(맞음 = Good, 틀림 = Again, miss ±1).

- 확대·축소: 헤더 도구(− 배율 + / 100% / 화면 맞춤), Ctrl+휠, 탐색 모드 `-` `=` `0`. 30%~200%. 배치·측정은 원래 px, 화면만 `scale` → 노드 드래그·너비 핸들은 배율로 보정. 빈 배경 드래그로 패닝.
- 플래시카드: 현재 개념과 노드별 평가 집계를 sessionStorage(`flash:<treeId>`)에 보관 → 새로고침해도 이어서 진행, '처음부터 다시'로 초기화.
- 저장: 편집 저장 트랜잭션을 줄 세우지 않고 즉시 시작(IndexedDB 가 순서 보장). 입력 직후 새로고침 시 유실 범위 축소.
