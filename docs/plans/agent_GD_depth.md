# agent GD — 시안 B 깊이 (`data-look='depth'`)

상위 plan: `orchestration_liquid_glass.md` §1 가드레일, §2 B, §3 공유 계약, §6 점검 도구. 근거: `docs/research/R5_liquid_glass.md`.

## 접근 방식

**논지: 드릴다운 = 유리판을 한 장씩 통과.** 위치(깊이)를 재질로 보여 준다. 표면에서 내려갈수록 빛이 줄어 배경·카드 색조가 깊어진다.

| 표현 | 기술 | 왜 |
|---|---|---|
| 깊이별 배경 | `.flash::before` 고정 레이어(z -1). `background-color`가 `--depth`를 읽고 전환된다. 위에서 내리는 빛은 깊을수록 약해진다 | `body`는 자손 `--depth`를 못 읽는다. 그라데이션은 전환이 안 되므로 색과 빛을 분리한다 |
| 지나온 유리판 | `.flash-concept`의 `box-shadow` 층(판마다 면 + 림). 판 k는 `clamp(0, depth-k+1, 1)`로 켠다. 최대 4장, 윗 여백을 깊이만큼 확보 | 요소 추가 없음, 정지 페인트. 바깥 그림자는 카드 안쪽에 그려지지 않아 글자 뒤에 판 경계가 없다(G7) |
| 카드 재질 | `--mat`: `--deep`을 `--d × step`만큼 섞은 표면색 + 알파. `backdrop-filter` 없음 | 300노드 성능, G2 |
| 에디터 깊이 | `.node-row`에서 `--d`, `--mat`, `--shadow`를 다시 선언. 얕을수록 그림자가 크고, 깊을수록 작다. `--heat`는 그대로 위에 섞인다 | 색조(푸른 계열)와 오답(붉은색)이 충돌하지 않는다(G9) |
| 목록 | 카드 아래로 판 2장이 비친다(아직 안 들어간 깊이). 위 = 지나온 판, 아래 = 남은 판 | 첫 화면에서 논지를 예고 |
| 조작 유리 | 공통 규칙 하나 + `--glass` 토큰. 굴절은 `.mode-tabs`만 | 틀 안 유리 금지. `.look-picker`와 `.dnd-bar`(모바일 시트 안)는 유리 없음 |
| 퀴즈 | `.dnd::before` 저채도 평면 배경 | 회상 중 시선 분산 방지 |
| 숙련도 비색 단서 | 띠 무늬: green 실선, lightgreen 점선, red 빗금, none 없음. 미니맵은 채움·점선·외곽선·빈칸 | G8 |

**토큰이 스위치다.** `--mat-a`와 `--glass-a`를 100%로 바꾸면 전부 불투명해진다. 투명도 줄이기·대비 높이기는 이 값과 `backdrop-filter: none`만 바꾼다.

검토한 대안:
- `.flash-card-wrap::before/::after`로 판 그리기: 2장이 한계라 버렸다. 그림자 층은 음수 spread 때문에 먼 판의 모서리가 덜 둥글지만, 원근감으로 읽혀서 받아들인다.
- `--surface` 자체를 반투명으로: `.toast`, `.badge.folded`가 `--surface`를 글자색으로 써서 글자가 비친다. 그래서 `--mat`을 따로 둔다.
- `@property`로 그라데이션 전환: `:root[data-look]` 스코프 밖 전역 규칙이 생겨서 뺐다.
- `.node-row.lifted`에 유리: G2 측정 대상(콘텐츠 카드)이라 불투명 + 큰 그림자로 처리한다.

주의: 기능 CSS는 지연 로드되어 `look.ts`보다 뒤에 온다. 같은 특이도면 기존 규칙이 이기므로 항상 더 높은 특이도로 쓴다.

## 변경 사항

- **에디터 지층을 `.outline`에서 `.graph-pan`으로 옮겼다.** 처음엔 `.outline`에 반투명 그라데이션 + 점 격자를 깔았는데 `perf`가 fps 22였다. 규칙을 하나씩 끄며 재 보니 원인은 유리가 아니라 스크롤러의 비단색 배경이었다(스크롤러가 투명이어도, 그라데이션을 스크롤러 밖 `.canvas::before`로 빼도 30대). 스크롤러를 불투명 단색으로 두고 지층을 스크롤되는 면에 깔면 75 이상이다. 위 = 표면, 아래 = 깊은 곳이 트리와 함께 움직여 논지에도 더 맞는다. 대신 이 시안에서 `.outline`은 반투명이 아니다.
- **숙련도 카드는 깊이 색조를 쓰지 않는다.** 처음엔 재질(`--mat`) 위에 숙련도 색을 올렸는데 깊은 곳에서 초록이 푸른색에 섞여 탁해졌다(G8). 숙련도가 있는 카드는 맑은 판(`--plain`) 위에 올리고, 깊이 색조는 숙련도 없는 카드에만 남긴다.
- **`.flash` 안의 `--muted`를 `--text`로 올렸다.** 라이트에서 깊이 5의 배경 위 경로·집계가 `--text-2`로도 4.5:1에 못 미쳤다.
- **`.keys`, `.tree-menu-list`는 `--glass-a` 재선언 대신 배경을 직접 준다.** `--glass`는 `:root`에서 계산되어 내려오므로 자식에서 바꿔도 반영되지 않는다.

## 검증 방법

- G1~G4: `tools/look` 4조합 report.json. G6: `-g perf`.
- 도구는 깊이 0~1만 지난다. 깊은 화면은 스크래치 폴더의 스크립트로 찍고 눈으로 본다.
- G7~G9: PNG를 직접 연다.
- 스코프: 스크립트로 CSS 선택자를 전수 검사.

- 스코프 검사: 선택자 85개, keyframes 1개, 위반 0건.
