# 오케스트레이션 plan — UX 다듬기 (마이크로 인터랙션 · 피드백 애니메이션 · 레이아웃 · 용어)

요구사항(사용자 원문 요약): 사용을 더 매끄럽게, 기능을 **텍스트를 늘리지 않고** 직관적으로 파악하게, 레이아웃을 깔끔·정돈되게 하는
마이크로 인터랙션 · 피드백 애니메이션 · 레이아웃 · 용어 변경을 연구 후 적용. 기능 설명 텍스트는 최대한 자제.

## 0. 사용자 결정 (질문 답변)
- 모드 이름: 편집 / 플래시카드 / **빈칸 퀴즈** / **백지 퀴즈** (기존 D&D 퀴즈 / 백지 D&D)
- 플래시카드 평가 버튼: **알음 / 모름 유지**

## 1. 연구 요약 → 적용 원칙
현재 화면(1440×900 스크린샷)과 코드를 검토하고, 널리 쓰이는 지침(NN/g 마이크로인터랙션·확인 대화상자 남용,
Material 모션 시간·이징, Apple HIG 피드백, Fitts/Hick 법칙, WCAG 2.3.3 reduced motion)을 적용했다. 별도 웹 조사는 하지 않았다.

| 원칙 | 근거 | 이 앱에 적용 |
|---|---|---|
| P1 행동마다 즉시·국소 피드백 (트리거 → 반응 → 결과) | 마이크로인터랙션 4요소 | 누름 축소(.97), 놓기 착지 pop, 평가 즉시 색 채움, 오답 shake |
| P2 모션은 짧게: 100–200ms 반응, ≤320ms 전환, 들어올 땐 ease-out | Material motion | `--t-fast 120 / --t-med 200 / --t-slow 320`, `--ease-out`, `--ease-spring` |
| P3 설명 대신 어포던스·상태로 알린다 | 점진적 공개, 시그니파이어 | 긴 안내문 삭제 → 드래그 중 빈칸 강조, 커서, 아이콘+툴팁, 빈 상태에서만 안내 |
| P4 확인창 대신 되돌리기 | NN/g "Confirmation dialogs" | 노드 삭제는 즉시 + 토스트 [실행 취소] |
| P5 상태 메시지는 흐름을 막지 않게, 레이아웃을 밀지 않게 | 비모달 피드백 | 상시 초록 상태 박스 → 하단 토스트 |
| P6 중복·잡음 제거, 주 행동 1개만 강조 | Hick, 시각 위계 | 100% 버튼 중복 제거, 비활성 버튼은 숨김, 주 버튼 1개 |
| P7 위치 변화는 이어서 보이게 (연속성) | 공간 연속성 | 그래프 재배치 시 카드가 미끄러져 이동 |
| P8 움직임 줄이기 설정 존중 | WCAG 2.3.3 | 전역 `prefers-reduced-motion` 규칙(선행 작업에서 처리) |

### U1 에디터 (agent UE)
완료 기준:
1. **상태 박스 제거**: `.status` 초록 박스 대신 `toast()` 사용. 사이드 패널 맨 위가 노드 패널로 시작한다.
2. **삭제 = 즉시 + 되돌리기**: Delete 키는 `confirm()` 없이 지우고 `toast('"X" 삭제', {label:'실행 취소', run: undo})` 를 띄운다. 실행 취소는 기존 undo 스택을 쓴다.
3. **확대 도구 정리**: [− 배율 +] 묶음 + [화면 맞춤] 아이콘 버튼 + [자동 정렬] 아이콘 버튼. 중복된 "100%" 버튼은 없애고, 배율 숫자를 누르면 100%로 돌아간다. 자동 정렬은 옮긴 노드가 있을 때만 보인다(비활성 상태로 남기지 않음). 접근 이름(`축소 / 확대 / 화면 맞춤 / 자동 정렬`, output `배율`)은 유지한다.
4. **사이드 패널 정돈**:
   - 내용 placeholder 는 "내용" 한 단어로 줄인다.
   - "개요 붙여넣기 · 내보내기"는 루트만 있는 빈 트리일 때만 펼친 상태로 시작한다.
   - "단축키" 문단을 없애고, `?` 키나 `?` 버튼으로 여는 키 목록 팝오버를 둔다. 목록은 `<kbd>` 와 2~3단어 동작 이름만 쓰고 문장은 쓰지 않는다.
5. **그래프 모션**:
   - 재배치(추가·삭제·접기·자동 정렬) 때 카드가 `left/top` 트랜지션(`--t-med`, `--ease-out`)으로 이동한다. 드래그 중인 카드와 그 하위는 트랜지션 없이 즉시 따라온다.
   - 새로 생긴 카드는 `rise`로 등장한다.
   - 엣지는 카드와 어긋나 보이지 않게 한다. CSS `d` 트랜지션을 쓰거나, 이동 중에는 엣지를 잠깐 흐리게 한다. 방식은 에이전트가 선택한다.
6. **드래그 피드백**: 끄는 카드는 들어 올린 느낌(`--shadow-lift`, scale 1.02)을 준다. 놓으면 원래 그림자로 돌아온다.
7. **선택·편집 피드백**:
   - 선택 링은 트랜지션으로 바뀐다.
   - 제목 확정 시 카드가 짧게 반짝이지는 않는다(과함). 대신 오답 농도(`--heat`) 변화는 트랜지션으로 보인다.
   - 루트 카드에서 `+ 내용` 버튼과 접기 배지가 겹치지 않는다.
8. **너비 핸들 어포던스**: 호버하면 가장자리 막대가 보인다(기존). 놓으면 단계 폭으로 스냅되는 트랜지션이 있다.

### U2 플래시카드·오늘의 복습 (agent UF)
1. **펼침 모션**:
   - 개념 카드를 누르면 하위 목록이 높이와 투명도로 부드럽게 열린다(기존 stagger 유지).
   - 카운트 칩은 `하위 N개` + 회전하는 셰브론(▾)으로 보여 준다. "눌러서 펼치기 / 접기" 문구는 없앤다.
   - "하위 N개 · 더 들어가기 →" 는 `↳ N` 아이콘 버튼으로 바꾸고, 툴팁(title)으로 "더 들어가기"를 알린다.
2. **평가 피드백**:
   - [알음]/[모름]을 누르면 결과 칩이 `pop` 으로 나타나고, 카드 상태색이 트랜지션으로 채워진다.
   - [모름]은 카드가 한 번 `shake` 한다.
   - 헤더 집계 숫자는 바뀔 때마다 `pop` 한다.
3. **다음 행동 안내**: 현재 카드의 하위를 모두 평가하면 [다음 개념 →] 버튼이 `pulse-ring` 으로 한 번 강조된다. 텍스트 안내는 없다.
4. **키보드**:
   - 펼친 상태에서 `1`=첫 미평가 하위 알음, `2`=모름, `→`/`Enter`=다음 개념.
   - 버튼 툴팁(title)에만 단축키를 표시한다. 화면 문구는 추가하지 않는다.
5. **잡음 제거**:
   - 루트에 있을 때는 경로(breadcrumb)를 숨긴다(항목 1개뿐이라 의미 없음).
   - 미니맵 캡션 "전체 트리 · 강조 = 현재 개념"을 삭제한다.
   - 요약 화면 숫자는 count-up 대신 `pop` 으로 보인다.
6. **오늘의 복습**: 진행 막대가 트랜지션으로 차오르고, 카드 전환 시 `rise` 로 등장한다.

### U3 빈칸 퀴즈·백지 퀴즈 (agent UD)
1. **안내문 삭제**: 두 화면 상단의 `.dnd-hint` 문단을 지운다. 대신:
   - 카드를 집으면(드래그 시작 또는 탭 선택) 놓을 수 있는 빈칸과 노드가 `pulse-ring`/점선 강조로 드러난다. 집지 않았을 때는 조용하다.
   - 트레이 카드는 `cursor: grab` 과 호버 시 들림으로 끌 수 있음을 알린다.
   - 빈칸에는 아무 글자도 없다. "여기에 놓기" 문구 대신 강조로만 표시한다.
2. **착지·되돌림 모션**: 놓인 카드는 `pop` 으로 자리를 잡는다. 트레이로 돌아간 카드는 `rise` 로 들어온다.
3. **채점 피드백**:
   - 정답과 오답 표시가 왼쪽 위부터 순서대로(stagger 30–40ms) 나타난다. 오답 카드는 한 번 `shake`, 점수는 `pop` 한다.
   - 만점이면 점수에 짧은 강조(`pulse-ring`)를 준다. 문구 "— 완벽해요!"는 유지해도 된다.
4. **진행 표시**: "0 / 6 배치" 텍스트를 얇은 진행 막대 + 숫자(`3/6`)로 바꾼다. 다 놓으면 [채점] 버튼이 `pulse-ring` 으로 한 번 강조된다. "모든 카드를 놓았어요. 채점해 보세요." 문구는 삭제한다.
5. **범위 선택**: `범위` 라벨은 남긴다(짧음). select 는 툴바 높이에 맞춘다.
6. **용어**: 화면 안의 "D&D" 표기를 모두 없앤다(모드 이름은 헤더가 담당).

### U4 트리 목록 (agent UL)
1. **카드 정돈**:
   - 카드 전체가 편집으로 가는 큰 클릭 영역이 되고, 호버 시 들림 효과를 준다.
   - 학습 모드 링크(플래시카드 · 빈칸 퀴즈 · 백지 퀴즈)는 아이콘+짧은 이름의 한 줄 세그먼트로 보여 준다. 줄바꿈이 없어야 한다.
   - 접근 이름이 `편집`인 링크는 유지한다(E2E 계약).
2. **이름 변경**: `prompt()` 를 쓰지 않는다. 제목을 더블클릭하거나 ⋯ 메뉴 → 이름 변경으로 카드 안 인라인 입력을 연다. Enter 로 확정, Esc 로 취소한다.
3. **보조 행동 숨김**: [이름 변경]/[삭제] 상시 버튼 대신 카드 오른쪽 위 `⋯` 메뉴(네이티브 `<details>` 또는 popover)를 쓴다. 삭제는 학습 기록까지 지우므로 `confirm` 을 유지한다.
4. **새 트리**: 만들면 목록에서 새 카드가 `rise` 로 등장하고 짧게 강조된다. 입력칸 버튼 문구는 "만들기" 또는 그대로 둔다.
5. **헤더 정돈**: "학습 기록 내보내기(JSON)" 를 아이콘 버튼(⤓, 툴팁 "학습 기록 내보내기")으로 축소한다.
6. **빈 상태**: 트리가 없을 때 점선 박스에 한 줄 + 입력칸으로 포커스를 이동한다(문구 1줄 유지).

## 3. 공유 계약

### 3.1 모션 토큰·keyframes (index.css, 변경 금지 — 사용만)
`--t-fast 120ms` · `--t-med 200ms` · `--t-slow 320ms` · `--ease-out` · `--ease-spring` · `--shadow-lift` · `--ok` · `--warn`
keyframes: `rise`(아래에서 떠오름), `pop`(착지 튕김), `shake`(오답 흔들림), `pulse-ring`(accent 링 퍼짐, 1회)
전역 reduced-motion 규칙이 모든 애니메이션·트랜지션을 1ms 로 만든다 → 기능은 애니메이션 완료에 의존하면 안 된다 (animationend 대기 금지).

### 3.2 토스트 API (features/Toast.tsx, 변경 금지)
```ts
toast(text: string, action?: { label: string; run: () => void }, ms = 4000): void
```

### 3.3 E2E 계약 셀렉터 (유지 필수 — 바꿔야 하면 멈추고 보고)
- 목록: `getByLabel('새 트리 제목')` 입력(+Enter 로 생성), 카드 안 `getByRole('link', {name:'편집'})`

## 4. 가정 및 미결
- 가정: 에이전트 최대 4, E2E 는 사용자에게 보이는 핵심 흐름(기존 9개) + 이번 변경 검증 2~3개. 통합 후 오케스트레이터만 실행.
- 가정: 애니메이션은 CSS 우선, 라이브러리 추가 없음(의존성 변경 금지).
- 가정: 다크 모드에서도 같은 토큰으로 동작해야 한다 (하드코딩 색 금지, 기존 `--*` 사용).
- 미결: 실제 체감(속도·과함)은 사용자가 8001 에서 확인 후 조정.
