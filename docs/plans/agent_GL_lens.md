# agent GL plan — 시안 A 렌즈 (`data-look='lens'`)

상위 문서: `docs/plans/orchestration_liquid_glass.md` §1·§2·§3·§6, `docs/research/R5_liquid_glass.md`.

## 접근 방식

**논지를 화면에서 읽히게 하는 네 가지 장치**

1. **모양으로 나눈 두 재질.** 콘텐츠는 모서리가 작은(10px) 불투명 종이에 짧은 접촉 그림자, 조작은 완전한 캡슐(999px)에 림·스페큘러. 색이 아니라 모양으로 레이어가 구분된다.
2. **콘텐츠가 실제로 유리 아래를 지나간다.** 데스크톱 에디터는 캔버스를 화면 끝까지(상단 바 아래까지) 펼치고, 상단 바와 트리 헤더 캡슐이 그 위에 뜬다. 다른 트리 화면도 트리 헤더가 sticky 캡슐이다. 유리 위 스크롤 가장자리 페이드로 글자를 보호한다.
3. **활성 탭 = 캡슐에 맺힌 물방울.** 틴트 없는 렌즈(위 스페큘러, 아래 커스틱, 접촉 그림자). 글자 색은 `--text` + 굵기로만 상태를 표시한다.
4. **끄는 카드만 맑은 유리.** `.dnd-ghost`는 거의 흐리지 않아 빈칸이 비치고, 가장자리만 `#lg-lens`로 굽는다. 틴트 면은 `button.primary`뿐이다(진행 막대·경로·루트 카드는 먹색 중립).

**기술 선택**

| 결정 | 선택 | 대안과 이유 |
|---|---|---|
| 캡슐 안 렌즈 | 유리를 `::before`에 건다 | 요소 자체에 걸면 자식의 backdrop root가 되어 물방울이 아무것도 못 본다(§3.4). 의사 요소는 형제라 안쪽 물방울이 뒤를 볼 수 있다 |
| 림 | `::after` + `mask` exclude 1px 그라데이션 | `border-image`는 둥근 모서리에 안 맞는다 |
| 에디터 전폭 | 그리드 겹침 + 음수 margin, 문서 흐름 유지 | `position: fixed`는 포커스·스크롤·E2E 위험이 크다 |
| 숙련도 비색 단서 | 카드 띠 패턴(실선·점선·사선), 미니맵 도형(둥근 채움·점선 테두리·각진 사각·빈 칸) | 색 외 단서 요구(G8). 도형은 `rx`·`stroke-dasharray`로 정지 비용 없음 |
| 굴절 범위 | 물방울, `.zoom-tools`, `.dnd-ghost`만 | 큰 면적의 `feDisplacementMap`은 CPU 부담(R5). `perf` 확인 |
| 접근성 | 토큰 `--glass-*`를 미디어 쿼리에서 불투명으로 교체, 굴절은 쿼리 조건에서 제외 | 규칙을 표면마다 중복하지 않는다 |

## 변경 사항

- 트리 헤더 전체(제목+탭+도구)를 넓은 화면의 유리 캡슐로 올렸다. §3.3 목록에는 `.mode-tabs`만 있지만, 캔버스 위에 뜨면 맨 제목 글자가 카드 글자와 겹치기(G7) 때문이다. 캡슐 안 탭은 재질을 없앴다.
- 유리 요소의 `transition-property`를 `height`로 제한했다. 전역 reduced-motion 규칙의 기본값 `all`이 `backdrop-filter`를 1ms 트랜지션시켜, 투명도 줄이기를 켠 순간 유리가 남는 것으로 측정됐다.
- 데스크톱 에디터에서는 스크롤 가장자리 페이드(`body::after`)를 뺐다. 스크롤마다 다시 합성되는 비용(변형 측정 +5fps)이 들고, 카드는 이미 유리에 흐려진다.
- 끄는 카드는 글자 있는 칸(찬 빈칸·노드·카드) 위에서 맑기를 포기하고 굵은 재질이 된다. 맑은 상태에서는 아래 글자가 겹쳐 보였다(G7).

## 결과

- 점검 도구 네 조합 위반 0건(스크린샷 52장 + dnd-drag 4장, 강제 상태 추가 캡처 포함).
- `perf`: **절대 기준 50은 이 환경에서 달성·확인하지 못했다.** 도구 측정 lens 29~45. 같은 시간대 기존 디자인도 19~40이다(GD·GF·8001 서버와 Edge 다수가 동시 실행 중이라 기준선 56이 재현되지 않음). 번갈아 잰 마지막 4쌍 평균은 기존 30.5, lens 33.
- 알려진 한계: 맞춤(`fitZoom`)은 캔버스 높이 전체로 계산하므로 위쪽 여백만큼 아래가 약간 잘려 스크롤이 필요하다(TS 수정 없이는 해결 불가).
