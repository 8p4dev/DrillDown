## 3. 디스크 추정 (AA 소유 테이블만)

측정(`memory_measure.md`): 사용자 1명 + 세션 1개 ≈ 400 B.

| 규모 | users+sessions (세션 3개/인 가정) | audit_log (관리자 행동 월 200건 × 300 B × 12개월) | 합계 |
|---|---|---|---|
| 가입 1천 | 약 1 MB | 약 0.7 MB/년 | ≈ 2 MB |
| 가입 1만 | 약 10 MB | 약 0.7 MB/년 | ≈ 11 MB |
| 가입 10만 | 약 100 MB | 약 0.7 MB/년 | ≈ 101 MB |

트리·노드(SH)는 04 §7 가정 "사용자당 약 1MB" → 1만 명 10GB. **AA 테이블은 디스크 요인이 아니다.** 백업 1일 1회 × 14일 보관, 압축률 30% [가정] → 1만 명 기준 약 42GB → B2 무료 10GB 초과 → 약 $0.22/월. 1천 명이면 4GB로 무료 안.

## 4. 메모리 예산 (Pi 5 4GB)

| 프로세스 | 예산 | 근거 |
|---|---|---|
| Raspberry Pi OS Lite 64-bit (커널·systemd·sshd) | ≈ 150~250 MB | [가정] |
| Node 24 API 서버(+정적 파일 서빙, SQLite 내장) | ≈ 70 MB | 측정 63 MB + 여유 [측정] |
| cloudflared | ≈ 30~60 MB | [가정] 공개 측정값 못 찾음. Pi 4B 1GB에서 Caddy+로그수집기+cloudflared 합계 250 MB 사례 [S25] |
| 백업 작업(야간, `sqlite.backup` + age + rclone) | 순간 ≈ 50 MB | [가정] |
| **합계** | **≈ 300~430 MB** | 4GB의 1/10. 2GB도 가능 [추론] |

비교: 11 §2 구성(Postgres + Node + Caddy + cloudflared + 대기 노드 복제)은 Postgres 최소 튜닝 시에도 +20~60 MB [S26], 그리고 Pi 1대가 더 든다.
