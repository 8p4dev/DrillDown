# 전 분야 개선 요약 (2026-11-10)

DrillDown 코드 전체를 네 분야로 나눠 감사했다. 기술 문제와 사용자 불편 81건을 찾았고, 그중 74건을 고쳤다. 위험이 큰 7건은 미뤘다.

- 계획과 작업 분할: `docs/plans/orchestration_improve.md`
- 워커별 상세 계획과 결과: `docs/plans/agent_{WE,WS,WY,WH}_improve.md`
- 검증: typecheck(e2e 포함)·lint 경고 0·`npm run check` 전부 통과. E2E 22/22(기존 20 + 새 회귀 2).
- 예산: precache 637.8 KiB(한도 640). 첫 화면 JS gzip 70.5 KB(한도 120).

## 가장 중요한 다섯 가지

| | 문제 | 지금 |
|---|---|---|
| 1 | 다른 기기에서 받은 학습 기록이 있으면 플래시카드·복습 화면과 채점이 오류로 멈췄다. 두 기기 이상 쓰는 로그인 사용자는 전부 해당됐다 | 받은 기록의 날짜를 되살린 뒤 계산한다. 회귀 E2E 추가 |
| 2 | 동기화가 끝난 뒤 실행 취소·다시 실행을 하면 서버가 그 변경을 무시했다. 이 기기와 다른 기기의 내용이 영영 달라졌다 | 되살린 노드에 새 수정 시각을 붙인다 |
| 3 | 다른 기기의 변경이 들어온 뒤 실행 취소하면, 그 기기가 방금 만든 노드가 지워졌다 | 다른 기기 변경이 들어오면 되돌리기 목록을 비운다 |
| 4 | 로그인 없이 아주 큰 요청 하나로 서버(라즈베리 파이) 메모리를 소진시킬 수 있었다 | `/api/*` 요청 본문을 약 2 MB 로 제한(413) |
| 5 | 병합 대화를 Esc 나 바깥 탭으로 닫으면 동기화가 새로 고칠 때까지 시작되지 않았다 | 선택하기 전에는 닫히지 않는다. 회귀 E2E 추가 |

## 분야별 변경

### 데이터·동기화·서버
- **실행 취소와 학습 기록**: 노드를 지웠다가 되돌리면 학습 기록(카드 색, 다음 복습일)도 돌아온다. 같은 세션 안에서만 된다.
- **긴 내용**: 내용 5,000자를 편집기에서 막는다. 넘는 입력은 토스트와 함께 되돌린다. 개요 가져오기도 잘라 넣는다. 전에는 서버가 거부해서 그 노드가 다른 기기로 가지 않았다.
- **트리 제목**: 트리 제목과 루트 노드 제목이 기기 사이에서 어긋나던 문제를 고쳤다. 이제 루트 노드 제목이 기준이다.
- **형제 순서**: 순서 값이 같은 형제를 화면마다 다르게 늘어놓던 문제를 고쳤다. 정렬 기준을 하나(`byOrder`)로 통일했다. 맨 끝이 아닌 자리에 계속 끼워 넣다 순서 값이 겹칠 상황이면 형제 번호를 다시 매긴다.
- **서버 되감김**: 서버 DB 를 백업에서 복원했거나 정전으로 마지막 기록이 사라졌을 때, 기기가 변경을 건너뛰던 문제를 고쳤다. 이제 전체 재동기화로 넘어간다. SQLite 를 `synchronous=FULL` 로 바꿨다.
- **오래 꺼져 있던 기기**: 이런 기기가 다른 곳에서 지운 트리를 되살리던 문제를 고쳤다. 최근 7일 안에 고친 트리만 다시 올리고, 나머지는 그 기기의 휴지통으로 보낸다. 휴지통에서 7일 안에 복구할 수 있다. 휴지통에서 복구한 트리가 서버에 빈 트리로만 생기던 문제도 함께 막았다.
- **백업 가져오기**: 가져온 트리가 서버의 삭제 기록에 밀려 휴지통으로 가던 문제를 고쳤다.
- **보안과 개인정보**:
  - 보안 헤더를 붙인다. 프레임 삽입 차단과 MIME 추측 차단이다.
  - 요청 로그에서 공유 링크 토큰을 가린다.
  - 탈퇴한 사용자의 신고자 기록을 비운다.
  - 다른 계정으로 새로 시작할 때 이전 계정의 로컬 사용 기록을 지운다.
  - 정지된 사용자의 공개 트리를 갤러리와 공유 링크에서 숨긴다.
- **운영**:
  - 일일 정리 작업에서 사용자 하나가 실패해도 나머지 정리는 계속한다.
  - 외부 백업을 설정했는데 필요한 도구가 없으면 백업을 실패로 보고한다.
  - 카카오 연결 해제 알림이 로그인 요청 수 제한에 걸려 버려지지 않게 한도를 분리했다.
- **로컬 기록 정리**: 로컬 사용 기록(events)은 180일이 지나면 지운다.

### 편집기·트리 목록
- **단축키**:
  - Ctrl/⌘+K 로 검색을 연다. 검색은 제목뿐 아니라 내용과 별칭에서도 찾는다.
  - 맥의 delete 키(Backspace)로도 노드를 지운다.
  - 단축키 표에 `?` 와 Ctrl+Y 를 넣었다.
- **AI 초안**: 가져오기 패널에 'AI 프롬프트 복사' 버튼을 넣었다. AI 에게 들여쓰기 개요로 답하라고 요청하는 문구가 복사된다. AI 의 답은 캔버스에서 Ctrl+V 로 바로 붙여 넣을 수 있다. 붙인 내용은 선택한 노드 아래로 들어간다.
- **개요 복사**: 여러 줄 내용은 개요 복사에서 빠진다. 이제 그 개수를 토스트로 알린다.
- **끌기**: 확대·축소 배율과 상관없이 같은 손 떨림 폭에서 끌기가 시작된다. 전에는 많이 축소한 상태에서 클릭만 해도 카드가 움직였다.
- **화면 표시**:
  - 다른 기기에서 받은 학습 기록이 카드 색에 바로 반영된다.
  - 제목 없는 노드를 지우면 `"" 삭제` 대신 '제목 없음' 으로 알린다.
- **입력**:
  - 트리 제목 입력에 길이 제한을 걸었다.
  - 한글 조합 중 Enter 를 판정하는 코드를 하나로 합쳤다. 사파리에서 이름을 바꾸다 조합 중에 확정되던 문제가 사라진다.
- **속도**: 큰 트리에서 보이는 줄 계산, 가지 복제, 개요 변환, 하위 노드 찾기가 노드 수에 비례하는 시간으로 끝난다. 전에는 노드 수의 제곱에 비례했다(하위 노드 찾기 5,000 노드 기준 약 240 ms).

### 학습·복습
- **다시 평가**: 플래시카드에서 평가를 고치면 이전 평가를 대체한다. 전에는 복습이 두 번 기록돼 다음 복습일이 크게 당겨졌다.
- **저장 실패**: 채점 저장에 실패하면 알리고 화면의 평가를 되돌린다. 전에는 아무 표시 없이 사라졌다.
- **'모름만 다시'**:
  - 새로 고쳐도 이어 할 수 있다.
  - '더 깊이' 를 눌렀을 때 1번 카드로 튀지 않는다.
- **약점만**: 많이 틀린 개념만 모아 푸는 세션이다. 플래시 화면 헤더와 끝 요약에 버튼이 있다.
- **오늘의 복습**:
  - 한 번에 20개씩 나오고 '더 하기' 로 이어 간다.
  - 끝나면 알음/모름 수와 모른 항목을 요약해 보여 준다.
  - 섞기 버튼이 있다.
  - 상단 복습 수 배지가 채점 직후 바로 갱신된다.
- **다른 기기 변경**: 학습 화면이 다른 기기의 변경을 반영한다. 다른 기기에서 지운 노드에는 채점 기록이 남지 않는다.
- **빈칸·백지 채점**: 채점이 트랜잭션 한 번으로 끝난다. 큰 트리에서 빨라진다.
- **빈 트리**: 루트만 있는 트리는 '0/0 잘했어요' 대신 편집으로 가는 안내를 보여 준다.
- **접근성**:
  - 퀴즈에서 선택한 카드를 화면 낭독기가 읽는다.
  - Esc 로 선택을 해제한다.
  - '더 깊이' 버튼은 모바일에서 44 px 이다.
- **플래시 다시 시작**: 같은 자리에서 다시 시작하면 이전 펼침과 평가가 남아 있던 문제를 고쳤다.
- **코드 정리**: 버린 타이핑 채점 설계의 잔재 함수를 지웠다.

### 앱 공통·모바일·PWA·접근성
- **모바일 키보드**: 키보드 높이 추적을 앱 전체에서 켠다. 공유 보기, 계정, 복습 화면에서도 입력창과 토스트가 키보드에 가리지 않는다.
- **오류 화면**: 화면 하나가 오류로 깨져도 앱 전체가 하얗게 사라지지 않는다. '새로 고침' 버튼이 있는 오류 화면이 뜬다. 배포 직후 옛 파일을 못 찾는 경우도 잡힌다.
- **설치**: PWA 아이콘(192, 512, 마스커블 512)과 iOS 홈 화면 아이콘을 넣었다. 브라우저의 앱 설치 조건을 채운다.
- **시트**: 열린 시트 안에서 Tab 포커스가 바깥으로 빠지지 않는다.
- **공유·갤러리**:
  - 링크 복사가 막히면 '복사하지 못했습니다' 라고 알린다.
  - 갤러리 첫 페이지가 실패하면 '다시 시도' 버튼이 뜬다.
- **터치와 화면 낭독기**:
  - 공지 배너는 줄바꿈되고, 닫기 버튼과 공유 목록 버튼은 손가락 크기(44 px)다.
  - 상단 메뉴는 현재 화면을 화면 낭독기에 알린다(`aria-current`).
  - 이름이 같던 버튼('복구', '숨김', '기각')은 낭독기가 대상까지 함께 읽는다.
  - '더 보기' 메뉴는 실제로 없는 메뉴 키 조작을 내세우던 역할 표시를 뺐다. Esc 로 닫힌다.
- **첫 화면**: 첫 화면에서 전체 아이콘 파일을 내려받지 않는다.
- **개발 위생**:
  - e2e 코드도 타입 검사에 들어간다.
  - README 를 프로젝트 설명으로 바꿨다.
  - 안 쓰는 파일(`public/icons.svg`, `ui/Hint.tsx`)과 색 토큰을 지웠다.
  - 낡은 주석과 설계 문서의 상태 표시를 고쳤다.
  - `docs/CODEBASE.md` 의 "알려진 한계" 를 현재 상태로 갱신했다.

## 남은 한계

- 삭제를 되돌릴 때 학습 기록이 돌아오는 것은 같은 세션 안에서만이다. 새로 고친 뒤의 되돌리기는 노드만 되살린다.
- 플래시카드 평가를 새로 고침으로 복원한 뒤 다시 평가하면 기준 상태가 없어 복습이 두 번 기록된다.
- 오래 꺼져 있던 기기의 전체 재동기화(410) 경로, 일일 작업의 사용자별 실패 처리, 외부 백업 도구 확인은 코드 검토만 했다. 자동 테스트는 없다.
- 실기기(iOS·Android·카카오톡 인앱)와 실제 OAuth 왕복은 이번에도 검증하지 않았다.
