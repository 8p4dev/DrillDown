### 항목별 설명

1. **공개 전 입력(생성형 인출).** 지금 드릴다운은 [알음/모름]을 누르면 하위 노드가 바로 보인다. 그래서 떠올리지 않고 읽기만 해도 진행된다. 하위 항목을 먼저 입력하게 하고, 기존 텍스트 채점 엔진으로 노드별로 판정해 그 결과를 FSRS에 넣는다. 틀린 시도도 이후 학습을 돕기 때문에(Kornell 2009) 입력은 "모르겠음"으로 넘길 수 있게 한다.
   - UX: 카드 아래 "하위 3개를 떠올려 적어 보세요" 입력란 → Enter → 맞힌 자식은 초록 테두리, 빠뜨린 자식은 흐리게 공개.
2. **[알음] 등급 하향.** 1번이 들어오기 전까지의 최소 수정이다. 자기평가 [알음]을 `self_accept`(Hard, 연두 상한, 재확인 대기)로 기록하는 한 줄 수정이다. 03 §3.5의 규칙이 플래시카드 경로에만 빠져 있다.
   - UX: [알음]을 눌러도 색은 연두까지만 칠해지고, 툴팁에 "퀴즈로 확인하면 초록"이 표시된다.
3. **묶음 카드 + 선수 게이트.** 복습 카드를 "부모 X의 하위 항목은?" 하나로 묶고, 자식별로 부분 점수를 준다. 부모가 lapse 상태이면 자식 묶음은 오늘의 복습에서 뒤로 미룬다. 지금은 노드 단위 카드라 형제를 각각 따로 묻는다.
   - UX: 오늘의 복습 카드 한 장 = 부모 한 개. 결과 화면에 "4개 중 3개" 칩과 빠뜨린 자식이 표시된다.
4. **FIRe 암묵 크레딧.** 상위 묶음에서 성공하면 하위 묶음의 안정성을 할인된 비율로 올린다. 03 권고대로 할인율 0으로 출시하고, 하위 노드 회상률 로그가 쌓인 뒤 켠다. 3번이 먼저 있어야 한다.
   - UX: 사용자에게는 보이지 않는다. 설정에 "상위 복습으로 하위 복습 줄이기(실험)" 토글만 둔다.
5. **역방향·형제 단서.** "이 노드는 어느 가지에 속하나?", "A와 B는 어느 상위 개념에서 갈리나?"를 섞어 낸다. 부모라는 단서 하나에만 기억이 묶이지 않게 한다.
   - UX: 카드 상단에 노드 이름만 보이고, 미니맵에서 부모 위치를 탭해 답한다.
6. **혼합 복습.** 오늘의 복습을 트리별·가지별 블록이 아니라 비슷한 가지(같은 깊이의 형제 가지, 같은 과목의 다른 트리)끼리 섞어 낸다. 메타분석에서 단어 자료는 블록이 더 나았으므로 단순 용어 트리는 섞지 않는 옵션을 둔다.
   - UX: 복습 시작 화면의 "섞어서 / 트리별" 토글. 기본값은 섞어서.
7. **정교화 질문.** 리프 노드를 맞힌 뒤 "왜 이 부모 아래에 있나?"를 선택 입력으로 묻는다. 로컬에서는 입력만 받아 노드 내용 옆에 저장하고, 채점은 하지 않는다. 자동 피드백은 LLM 단계로 미룬다.
   - UX: 정답 직후 작은 "왜?" 칩 → 한 줄 입력 → 노드 메모에 "내 설명"으로 붙는다.
8. **확신도 + 고확신 오답.** 답을 입력한 직후 확신도(낮음/보통/높음)를 한 번 탭하게 한다. "높음인데 틀림"은 결과 화면 맨 위에 강조하고, 다음 날 다시 묻는다. 확신도는 FSRS 등급을 바꾸지 않고 우선순위만 바꾼다(자기평가 과신 방지).
   - UX: 제출 버튼이 세 개로 나뉜다(확신 낮음·보통·높음). 결과에는 "확신했는데 틀린 2개" 섹션이 뜬다.
9. **예상 vs 실제.** 백지 퀴즈를 시작하기 전에 "몇 %를 떠올릴 것 같나요?" 슬라이더를 보여주고, 끝나면 실제 재현율과 나란히 표시한다. 회차별 차이 추세를 트리 통계에 남긴다. 5.2절 실험의 보정 측정과 같은 데이터다.
   - UX: 시작 화면 슬라이더(0~100) → 결과 화면 "예상 80% · 실제 62% (과신 18%p)".
10. **약점 집중 세션.** 이미 있는 `miss` 점수와 최근 Again 기록으로 상위 N개 노드(또는 그 부모 묶음)만 모아 5분 세션을 만든다. 트리 목록에는 "약점 가지" 리포트를 붙인다. 09에서 유료 후보인 "약점 기록"의 무료 체험판이 된다.
    - UX: 트리 ⋯ 메뉴 "약점만 복습(12)" → 빠뜨린 횟수 순 카드 세션 → 끝나면 "다시 빠뜨린 3개".
11. **시험일 역산.** 트리나 과목에 시험일을 입력하면 ① 남은 기간에 맞춰 목표 기억률과 신규 노드 도입 속도를 계산하고 ② D-7부터 전 노드를 한 번 이상 인출하는 마지막 패스를 넣고 ③ 놓친 날은 재분배한다. 연 1회 시험이라는 타깃(국가고시)에 가장 직접적인 기능이다.
    - UX: 트리 헤더 "D-87" 배지 → 탭하면 "오늘 할 양 34노드 · 예상 완주일 D-12".
12. **목표 기억률·부하 예측.** 설정에 목표 기억률 슬라이더(0.80~0.95)와 "앞으로 30일 일일 복습량" 막대를 둔다. 요일별 가벼운 날(Easy Days)은 2차로 넣는다. 개인 파라미터 최적화는 로그가 충분히 쌓인 뒤 WASM 바인딩으로 검토한다.
    - UX: 슬라이더를 움직이면 아래 막대 그래프의 일일 복습량이 바로 바뀐다.
13. **짧은 세션 캡 + 일일 목표.** 세션 길이를 기본 10분(또는 30노드)으로 자르고, 끝나면 "오늘 목표 달성"과 남은 양을 보여준다. 스트릭·알림은 R4 범위라 여기서는 세션 단위 설계만 다룬다.
    - UX: 상단 얇은 진행 바 "8/10분" → 다 차면 "오늘은 여기까지 · 내일 복습 21개".
14. **난이도 사다리.** 지금 D&D는 정답 카드만 주기 때문에 마지막 몇 장은 소거법으로 맞출 수 있다. 다른 가지의 카드를 오답 보기로 섞고, 정답률에 따라 다음 단계(부분 백지: 부모 라벨만 줌)를 제안한다. 2회독 이상 사용자는 바로 완전 백지로 간다.
    - UX: 퀴즈 결과 화면 "85% 달성 → 다음은 부분 백지" 버튼.
15. **기출 연동.** 노드에 기출 지문(O/X)을 붙이고 출제 횟수를 표시해 복습 우선순위에 가중한다. 기출 DB 확보·저작권·검수가 필요해 서버와 콘텐츠 작업이 든다. 사용자가 직접 지문을 붙이는 로컬 버전(노드 메모 + "기출" 태그)이 S 크기 1단계다.
    - UX: 노드 옆 "기출 3" 배지 → 탭하면 지문 O/X 카드 세 장.
