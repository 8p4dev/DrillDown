# R6 — 모바일·접근성: 트리가 많고 클 때 (2026-11-08)

작성 R6. 환경: `PORT=4306 DATA_DIR=.research-data/R6`, 로그인 `R6`, Playwright(msedge) 폰 390×844(hasTouch·isMobile·DPR2), 태블릿 768×1024·1024×768(touch), 데스크톱 1280×800(키보드만), `reducedMotion: 'reduce'`. 예시 트리는 폰 화면에서 "개요 텍스트"에 붙여넣어 만들었다(222개 가져옴). 목록 51개(예시 + 짧은 제목 42 + 긴 제목 7 + 중간 실패로 생긴 같은 제목의 빈 트리 1). 스크립트는 스크래치 디렉터리(`r6/a~d.mjs`), 측정값은 같은 곳의 JSON.

근거 표시: **[실측]** 브라우저로 직접 해 보고 잰 것 / **[코드]** 코드에서 확인 / **[추정]** 확인 안 됨. 실기기(iOS·Android)와 실제 스크린리더(VoiceOver·TalkBack·NVDA)는 쓰지 못했다. 스크린리더 항목은 접근성 트리 스냅샷(`ariaSnapshot`)과 코드로 판단했다.

## 요약
1. **키보드 사용자는 에디터 트리에서 빠져나올 수 없다.** 트리에서 Tab을 누르면 빈 자식 노드가 생기고 그 제목 입력칸으로 포커스가 간다. 이후 Tab은 그 노드를 들여쓰기할 뿐이라 Tab 30번으로도 패널에 가지 못했다(치명). 스크린리더는 화살표로 선택을 옮겨도 아무것도 읽지 않는다(`aria-activedescendant` 없음).
2. **폰에서 노드 222개 트리는 가로 10,172px, 화면 28장 너비다.** 진입 배율 50%(하한), 글자 실효 약 7px이다. 터치만으로는 자식 추가·삭제·이동·잘라내기를 할 방법이 아예 없다(단축키 전용). 태블릿도 14,402px, 화면 20장 너비다.
3. **트리 50개 목록은 폰에서 9.3화면이고 검색이 없다.** 키보드로 마지막 카드까지 가려면 Tab이 400번 넘게 필요하다. 링크 이름이 모두 "편집"·"플래시카드"라 스크린리더로는 어느 트리인지 구별되지 않는다. 플래시 미니맵은 222노드에서 버튼 1.5×0.6px(탭 불가)이고, 82개 모두 Tab 정지점이다.

## 이미 잘 되는 것(재확인)
- **reduced-motion**: [실측] 노드·간선 트랜지션 1ms, `scroll-behavior: auto`, 뷰 트랜지션 꺼짐(`index.css:218-221`, `router.ts:85`). 플래시·빈칸도 별도 처리.
- **핀치 확대**: [실측] 두 손가락 벌리기로 50% → 139%. 앱이 직접 처리하고 페이지 확대는 막지 않는다(viewport meta에 `user-scalable=no` 없음).
- **가로 스크롤 없음**: [실측] 목록·에디터·플래시 모두 `scrollWidth` = 390. 넓은 그래프는 캔버스 안에서만 스크롤된다.
- **터치 대상 44px**: [실측] 모드 탭 약 90×44, 확대 도구 44×44, 목록 더 보기 44×44, 플래시 다음·요약 44px, 패널 서식 버튼 coarse 44px.
- **iOS 포커스 확대 방지**: [코드] coarse에서 입력칸 `font-size: max(16px, 1em)`(`index.css:133`, `editor.css:92`).
- **가상 키보드 대응 골격**: [코드] `visualViewport`로 `--kb`·`data-kb`를 갱신한다(`viewport.ts`). 키보드가 열리면 확대 도구 숨김, `scroll-margin-bottom: calc(var(--kb) + 1rem)`. 실기기 검증은 못 했다(02 §6 수동 체크리스트 M-항목에 맡김).
- **포커스 링**: [실측] 2px solid, 텍스트색. 목록 카드는 `::after` 오버레이 링.
- **랜드마크·언어**: [실측] nav·main·header(트리)·aside(패널), `lang="ko"`, 플래시 진행 `role=status`·복습 진행 `progressbar`.
- **본문 대비**: [계산] 밝은 테마 muted 5.81:1, 다크 7.16:1. 카드 테두리 3.14:1.
- **플래시 폰 화면**: [실측] 한 화면(844px)에 들어가고, 경로 nav가 깊이 5에서도 줄바꿈으로 넘침 없이 보인다(높이 43px).
