## 요약
1. 222노드 트리가 **가로 28,804px × 세로 931px(31:1)** 한 장으로 펼쳐진다. "화면 맞춤"은 최소 배율 30%에서 멈춰 222개 중 26개만 보이고 글자는 4.3px라서, **트리 전체를 볼 방법이 없다**. 서브트리만 보기, 레벨 단위 접기, 검색, 경로 표시도 없어서 사용자는 수평 스크롤로 헤매며 지금 어디 있는지 잃는다.
2. 위험도 1위는 **실행 취소**다. 접기는 실행 취소 대상이 아니어서, 루트를 접고 Ctrl+Z를 누르면 접기 대신 **화면에 보이지 않는 이전 동작(222개 가져오기)이 통째로 사라졌다**. 화면 이동도 설명 토스트도 없었다.
3. 권하는 순서는 서브트리 포커스(`rootId` 라우트 재사용)+경로 → 리프 세로 쌓기 배치 → 레벨 접기 → 검색·점프 → 실행 취소 위치 표시다. 대부분 S~M이고 의존성은 늘지 않는다. 별도 개요(리스트) 모드는 보류했다. **참고: 현재 에디터에는 "개요 모드"가 없다.** 그래프 하나뿐이고 개요는 텍스트 붙여넣기·내보내기 칸만 있다.
