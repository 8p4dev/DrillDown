## 1단계 — 깨진 것 수정·안전 카드

- 검색·공지 입력칸이 에디터 스타일에 가려지던 버그 수정. 계정 화면에 관리자 링크.
- 신고 큐를 트리별로 묶고, 건별 기각, 숨기면 같은 트리 신고를 한 번에 정리.
- 파괴 동작은 전부 2단계 확인. 점검 모드도 2단계 + 비로그인 배너.
- 대시보드에 백업·일일 작업 상태, 재시작 이후 5xx 카운터, 개발용 로그인(AUTH_FAKE) 켜짐 경고.

## 2단계 — 사건 대응·감사 불변·소명·약관

- 시스템 탭에서 전 세션 폐기(사건 대응), 운영 기록(사건·복원·메모)을 감사 로그에 남긴다.
- 감사 로그는 DB 트리거로 수정 불가, 1년 미만 삭제 불가. 관리자가 사용자를 조회한 것도 기록.
- 숨김된 트리 소유자는 공유 시트에서 사유를 보고 소명을 보낼 수 있다. 관리자는 소명을 수용(=숨김 해제)·기각.
- 정지 사유를 로그인 화면에 표시. 이용약관 `#/terms` 신설(신고·게시중단·임시조치·소명·만 14세).

## 3단계 — 남은 요소 전부 (워커 3명 병렬)

### 운영 (ops)
- DB·WAL·빈 페이지·백업 폴더 합계, 메모리 사용률, 세션 수(총·만료 대기·관리자).
- 재시작 이후 카운터: 429 키별, 동기화 push/pull/410/밀림/버림, OAuth 콜백 실패. 브라우저 오류는 `POST /api/client-error` 로 받아 메모리에 10건.
- 서버 패널: 배포 커밋·빌드 해시, 재시작 필요 여부, [서버 재시작], [지금 백업]·[일일 작업](자식 프로세스라 서버가 멈추지 않음), [WAL checkpoint].
- 관리자 목록 읽기, OAuth 제공자 설정 상태, 복원 안내 + 로컬 백업 파일 목록(다운로드 없음).
- 감사 로그 필터(동작·대상·기간) + CSV 5,000행. 사용자 상세 패널, 다른 관리자 보호.

### 법규·통지 (legal)
- 권리자는 로그인 없이 `#/takedown` 에서 게시중단을 요구할 수 있고 트리는 즉시 숨겨진다. 흐름: 접수 → 숨김·소유자 통보 → 재개 예정 통보 → 재개 / 소 제기 / 확정 / 기각. 연락처는 처리 후 90일 삭제.
- 신고·게시중단 모두 접수번호를 받고 `#/report/<id>` 에서 연락처 없이 처리 상태만 본다.
- 정보주체 요청 큐: 이메일로 온 요청을 관리자가 직접 입력, 10일 기한, 지나면 빨강, 완료 시 감사 기록.
- 숨김 2종: 보류(30일 뒤 자동 해제, D-N 표시)와 확정. 열린 신고가 N건(기본 3)이면 자동 임시 숨김.
- 공지 복수(최대 10개, 160자, 링크·기간·대상 전체/로그인만), 점검 예약(시작·종료 시각, 요청 시각으로 판정, 스케줄러 없음). 비로그인은 `GET /api/notices` 로 받음.

### 제품 지표·피드백·스위치 (product)
- 학습 지표 카드(기간 30/90일/전체): K2(14일 내 같은 트리 백지 2회), 회독별 재현율, 자기채점·뒤집기 비율, 구조 오답, FSRS 예측 기억률, 활성화율(가입 72시간 내 백지 완료), 제공자별 가입, 신고 SLA, 1년 미접속, DB 크기/사용자. 1요청 100ms 단언.
- `daily_stats` 하루 1행(04:00) + SVG 직접 그린 선그래프. 공유 링크 조회 수 `view_count`.
- 피드백함: 계정 화면 버튼 → 시트 → `POST /api/feedback`(비로그인 5/시, 로그인 20/시). 내 피드백 상태와 운영자 메모를 계정 화면에서 봄. 90일 삭제.
- 운영 스위치 `flags`(갤러리·신고·별점·공개 전환): 화면과 서버 라우트가 같은 값으로 거절.
- 큐레이션: 시드 트리 표식, 추천 고정(갤러리 상단), 소유자·신고자 단위 신고 집계, 복제 계보.
- 보류(결정 필요): 후원 막대, 코호트, 허용 표현 승인 큐, 익명 핑, 태그, 웹 푸시, UTM. 지표 탭 하단에 한 줄로 표시.
